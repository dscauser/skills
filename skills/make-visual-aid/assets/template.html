# Improving dictated prompts
1. Read the dictation for intent.
2. Ask up to 3 questions, each with a suggested answer.
3. Return only the rewritten prompt.
## Examples
Before: "ok so um I need a welcome message for the new…"
After: "Write a short, friendly welcome email for…"
